# TASK-1: BIG DATA ANALYSIS USING PYSPARK

This project focuses on performing Big Data Analysis using PySpark on the Netflix Movies and TV Shows dataset. The main objective of this task is to demonstrate the ability to process, analyze, and extract meaningful insights from a large dataset using modern big data technologies. Big Data Analytics plays an important role in helping organizations understand trends, patterns, and user behavior from vast amounts of data.

## TOOLS AND TECHNOLOGIES USED

• Google Colab: Google Colab was used as the development platform for this project. It is a cloud-based environment that allows users to write and execute Python code without installing software locally.

• PySpark: PySpark is the Python interface for Apache Spark. It enables efficient processing and analysis of large datasets using distributed computing techniques.

• Python: Python was used as the programming language due to its simplicity and extensive support for data analysis.

• Matplotlib: Matplotlib was used to create visualizations and represent data graphically for better understanding.

## DATASET USED

The Netflix Movies and TV Shows dataset was used for this project. The dataset contains information about Netflix content, including title, type, country, release year, rating, and other details. It is suitable for demonstrating data processing and analytical capabilities using PySpark.

## IMPLEMENTATION

The dataset was uploaded into Google Colab and loaded into a PySpark DataFrame. A Spark Session was created to enable data processing operations. Initial exploration of the dataset was performed by displaying sample records, counting rows and columns, and examining the schema.

Several analytical operations were carried out, including summary statistics, identification of missing values, content classification analysis, rating analysis, release year trends, and country-wise content distribution. The processed data was then visualized using Matplotlib to make the results easier to interpret.

## INSIGHTS OBTAINED

• The dataset contains a large collection of Netflix content, including both Movies and TV Shows.

• Analysis showed that Movies are more numerous than TV Shows on the Netflix platform.

• Different content ratings such as TV-MA, TV-14, and PG were observed, indicating that Netflix serves audiences of various age groups.

• Content is available from multiple countries, demonstrating Netflix's global reach and diverse content library.

• Some columns contained missing values, highlighting the importance of data cleaning before performing advanced analytics.

• The release year analysis showed a significant increase in content production in recent years, reflecting the rapid growth of digital streaming services.

## APPLICATIONS

Big Data Analytics is widely used in industries such as entertainment, healthcare, finance, e-commerce, education, and social media. It helps organizations analyze large volumes of data, identify trends, improve decision-making, and optimize business strategies.

## CONCLUSION

This project successfully demonstrated Big Data Analysis using PySpark on the Netflix dataset. Google Colab provided a convenient cloud-based platform, while PySpark enabled efficient data processing and analysis. Through various analytical techniques and visualizations, meaningful insights were extracted from the dataset. This project provided practical exposure to big data technologies and enhanced understanding of real-world data analytics workflows, making it a valuable learning experience for future data-driven applications.
